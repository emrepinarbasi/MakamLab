# Privacy

MakamLab performs audio analysis and DOCX report generation locally on the
user's computer. It does not require an account, upload audio to a MakamLab
server, or include telemetry/usage analytics.

The application can open a documentation URL or prepare an e-mail link when the
user explicitly chooses that action. Those actions are then handled by the
operating system and the selected browser or mail application.

Generated reports can contain the local source path, recording name, checksum,
selected analysis settings, and measured results. Review a report before
sharing it if local paths or recording metadata are sensitive.
