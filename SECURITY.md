# Security policy

## Supported version

Security fixes are currently prepared for the latest 1.1.x source and release
packages.

## Reporting a vulnerability

Please do not publish exploit details in a public issue. Send a concise report
to `emrepinarbasi@gmail.com` with:

- affected version and operating system;
- reproduction steps;
- expected impact;
- relevant logs without private recordings or personal data.

You should receive an acknowledgement within seven days. A public issue or
advisory can be created after a fix or mitigation is available.

## Distribution integrity

Release packages must be checked against the published SHA-256 file. Version
macOS and Windows community packages do not have commercial platform
signatures; this limitation is documented rather than hidden. Never download a
package from an unlisted mirror solely to bypass an operating-system warning.
