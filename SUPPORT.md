# Support

Use GitHub Issues for reproducible bugs and feature requests. For academic
collaboration, licensing questions, or a report containing material that should
not be posted publicly, contact `emrepinarbasi@gmail.com`.

When reporting an analysis problem, include:

- MakamLab version and operating system;
- selected analysis module, makam/theory context, tonic frequency, and target
  pitch or interval;
- audio format, sample rate, channel selection, and approximate time range;
- the generated DOCX report if it contains no restricted material;
- a short description of the expected musical interpretation.

Do not attach copyrighted or confidential recordings unless you have permission
to share them.
